# Screenshots & Visual QA Captures

This directory contains visual captures, test screenshots, and QA inspection dumps generated during mobile application development and testing.

## Categories

- `dashboard_*.png`, `scrolled_dashboard.png`, `updated_dashboard.png`: Dashboard & Analytics views
- `flow_*.png`: Flow navigation screens (vendors, managers, reports, leaderboard, settings, drawer)
- `test_*.png`: Verification snapshots for specific actions (add vendor, visit, detail)
- `screencap_*.png`: Emulator capture audits
- `window_dump.xml`: UI hierarchy dump from Android test run
